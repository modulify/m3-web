# Adaptive content

`M3Adaptive` chooses content for the current viewport breakpoint. It can adapt navigation labels, headings, or other content without adding breakpoint props to each component. Only an exact matching breakpoint replaces the regular content. Resize the [example](?path=/story/components-m3adaptive--breakpoint-content) to see all three forms.

Do not use `M3Adaptive` throughout an app by default. Breakpoint-specific content is a last resort when a component cannot meet Material 3 guidance across supported widths or languages. First reconsider how the affected component is used, or replace it with a more suitable one where possible. Any variants should preserve the same meaning and function.

| Breakpoint | Viewport width |
| --- | --- |
| `compact` | below 600px |
| `medium` | 600–839px |
| `expanded` | 840–1199px |
| `large` | 1200–1599px |
| `extra-large` | 1600px and above |

## Vue API

Use `m3Adaptive()` directly in template interpolation for plain text. It reads the reactive breakpoint and updates when the viewport changes.

```vue
<script setup lang="ts">
import { m3Adaptive } from '@modulify/m3-vue/composables'
</script>

<template>
  {{ m3Adaptive('Incoming messages', { compact: 'Inbox', medium: 'Mail' }) }}
</template>
```

For richer content, use props or named slots. A selected function prop is called only when its breakpoint is active. It can return VNodes created with `h`. The component adds no wrapper element.

```vue
<M3Adaptive regular="Incoming messages" compact="Inbox" />

<M3Adaptive
  :regular="() => ['Incoming', h('br'), 'messages']"
  large="Inbox"
/>

<M3Adaptive>
  Incoming messages
  <template #compact>Inbox</template>
</M3Adaptive>
```

| Props and slots | Purpose |
| --- | --- |
| `regular` / default slot | Fallback content. The default slot takes priority. |
| `compact`, `medium`, `expanded`, `large`, `extra-large` | Exact breakpoint overrides as props or named slots. Slots take priority. The `extra-large` prop is `extraLarge` in JavaScript. |

For navigation, place `M3Adaptive` in the `#label` slot of `M3NavigationTab`. Keep labels short enough to fit without truncation in every supported language.

# Адаптивное содержимое

`M3Adaptive` выбирает содержимое по текущему классу ширины окна. Его можно использовать для подписей навигации, заголовков и других элементов без специальных props в каждом компоненте. Замена действует только на указанном классе ширины; иначе показывается обычное содержимое. Измените ширину [примера](?path=/story/components-m3adaptive--breakpoint-content), чтобы увидеть три формы записи.

Не используйте `M3Adaptive` повсеместно по умолчанию. Разное содержимое для разных классов ширины — крайнее средство, когда компонент не удаётся привести в соответствие с рекомендациями Material 3 на поддерживаемых ширинах или языках. Сначала пересмотрите способ применения проблемного компонента или, если ситуация позволяет, замените его более подходящим. Все варианты должны сохранять одинаковый смысл и назначение.

| Класс ширины | Ширина окна |
| --- | --- |
| `compact` | меньше 600px |
| `medium` | 600–839px |
| `expanded` | 840–1199px |
| `large` | 1200–1599px |
| `extra-large` | от 1600px |

## API Vue

Для простой строки вызывайте `m3Adaptive()` прямо в интерполяции шаблона. Утилита читает реактивный класс ширины и обновляет результат при изменении окна.

```vue
<script setup lang="ts">
import { m3Adaptive } from '@modulify/m3-vue/composables'
</script>

<template>
  {{ m3Adaptive('Входящие сообщения', { compact: 'Входящие', medium: 'Почта' }) }}
</template>
```

Для сложного содержимого используйте props или именованные слоты. Функция из prop вызывается, только когда выбран соответствующий класс ширины; она может вернуть VNode, созданный через `h`. Компонент не добавляет обёртку в DOM.

```vue
<M3Adaptive regular="Входящие сообщения" compact="Входящие" />

<M3Adaptive
  :regular="() => ['Входящие', h('br'), 'сообщения']"
  large="Входящие"
/>

<M3Adaptive>
  Входящие сообщения
  <template #compact>Входящие</template>
</M3Adaptive>
```

| Props и слоты | Назначение |
| --- | --- |
| `regular` / слот по умолчанию | Обычное содержимое. Слот имеет приоритет. |
| `compact`, `medium`, `expanded`, `large`, `extra-large` | Замены для точного класса ширины в виде props или именованных слотов. Слоты имеют приоритет. В JavaScript prop `extra-large` называется `extraLarge`. |

Для навигации поместите `M3Adaptive` в слот `#label` компонента `M3NavigationTab`. Подбирайте подписи так, чтобы они помещались без обрезки на каждом поддерживаемом языке.
