# Lists

Lists present related rows of text and optional visuals. Use them for settings, folders, messages, and other repeated information where each row should remain easy to scan.

## API

`M3List` renders a generic list container. `M3ListItem` renders a generic row with optional leading and trailing content, overline text, headline text, and supporting text.

Use plain children as the headline, or use `M3ListItem.Headline` when the headline needs explicit markup. `href`, `interactive`, or `onClick` make the row interactive.

## Accessibility semantics

- `M3List` uses a generic element with `role="list"`. Add `aria-label` or `aria-labelledby` when the list needs a programmatic name.
- `M3ListItem` uses a generic element with `role="listitem"` and a native link or button for interactive rows.
- Use `href` for navigation rows and `interactive`/`onClick` for in-place actions.
- For selectable option lists, set the container and rows to the appropriate composite pattern yourself, such as `role="listbox"`, `role="option"`, and `aria-selected`.

## Usage guidance

### Keep row content structured

Use overline and supporting text for secondary information instead of packing several unrelated fragments into the headline.

### Use trailing content sparingly

Trailing text and icons work best for concise metadata, status, or navigation affordances.
