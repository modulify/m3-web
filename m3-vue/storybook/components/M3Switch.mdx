# Switch

<Unstyled>
  Switches toggle the selection of an item on or off

  * Use switches (not radio buttons) if the items in a list can be independently controlled
  * Switches are the best way to let users adjust settings
  * Make sure the switch’s selection (on or off) is visible at a glance
</Unstyled>

## Accessibility semantics

<Unstyled>
  * Keep a visible label next to each switch control.
  * Expose checked state via `role="switch"` and `aria-checked`.
  * Use switches for immediate on/off state changes, not for multi-choice selections.
</Unstyled>
