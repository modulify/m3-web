# Date Picker

Date pickers let people choose a single date from a calendar grid. `M3DatePicker` provides the calendar surface; docked field flows are composed with `M3DatePickerField`, and modal flows are composed with `M3DatePickerDialog`.

## API

`M3DatePicker` is controlled by `value` and emits the selected date or date range through `onChange`. Use `layout="docked"` for Material's compact anchored surface; the default `layout="modal"` keeps the dialog-oriented header and geometry.

Compose docked actions with `M3DatePicker.Footer`. The picker owns the footer container and hides it while a month or year selection list is open.

`M3DatePickerField` combines an `M3TextField`, a calendar icon button, and a docked popper. It keeps the date picker value as `Date | null`, accepts safe text-field props such as `id`, `name`, `label`, `placeholder`, `invalid`, `disabled`, `readonly`, and `outlined`, and normalizes typed dates to `MM/DD/YYYY`. Use the root `className`, `popperClassName`, and rich `supportingText` when a form needs local composition hooks without taking over date picker state.

The docked field uses an outlined text field by default, opens the calendar in an elevated popup below the field, and keeps the popup interaction local to the form instead of interrupting the page with a modal dialog. A day click updates a local draft; Cancel discards it and OK commits it through `onChange`.

`M3DatePickerDialog` wraps the same calendar surface in a modal shell. It keeps a draft value while the dialog is open and commits it through `onChange` only after the user presses OK. Use `appearance="input"` to start from Material's modal date input layout; when `switchable` is enabled, users can switch between calendar and text input modes.

Use `firstDayOfWeek` to shift the grid start, `min`/`max` to disable dates outside an allowed range, and `availability` for custom date/year availability rules. Modal layouts keep a stable six-week grid. Docked layouts follow the M3 surface height for the visible month and render only the required four, five, or six rows.

The selected `value` and navigation `cursor` are separate states. Month arrows, month selection, year selection, and swipe navigation move only the cursor; they do not call `onChange` until a day is selected. Use `cursor` and `onCursorChange` when the calendar position must be controlled by parent state.

Use `navigation` to choose the navigation surface and `views` to declare the reachable `days`, `months`, and `years` states. The default `navigation="split"` stays outside the swipe track; `navigation="inline"` places the controls inside each swipable month page; `navigation="none"` hides them. Horizontal swipe between available months is always enabled on the calendar grid.

In the docked layout, month and year controls open separate vertical selection lists. The active list keeps its control enabled, disables the other control, and returns to the day grid after selection.

## Accessibility Semantics

- The root uses `role="group"` and is named by `label`.
- The days are exposed as a `grid` with one row per week.
- Grid month and year pickers use `grid` semantics; docked vertical selectors use explicit `list` and `listitem` roles through `M3List`.
- Each day is a native button with `aria-selected`.
- Disabled dates use native `disabled`.
- The month/year button uses `aria-expanded` while year selection is open.
- Modal flows use `M3DatePickerDialog`, which supplies dialog semantics through `M3Dialog`.

## Usage Guidance

Use the inline picker when the calendar is already the main task. Use modal composition when date selection interrupts a form or a compact workflow.

Use the docked field when date selection is part of a form and the selected value must remain visible in the field.

Keep range constraints visible through disabled dates instead of hiding days, so the month grid remains predictable.

## Docked field example

```tsx
const [date, setDate] = useState<Date | null>(new Date(2026, 6, 10))

<M3DatePickerField
  value={date}
  min={new Date(2026, 6, 3)}
  max={new Date(2026, 6, 24)}
  label="Trip date"
  name="trip_date"
  supportingText={<span>MM/DD/YYYY</span>}
  className="trip-date"
  popperClassName={['trip-date-popper', { 'trip-date-popper_open': true }]}
  placeholder="MM/DD/YYYY"
  onChange={setDate}
/>
```

## Modal dialog example

```tsx
const [opened, setOpened] = useState(false)
const [date, setDate] = useState<Date | null>(new Date(2026, 6, 10))

<M3DatePickerDialog
  opened={opened}
  value={date}
  label="Trip date"
  onToggle={setOpened}
  onChange={setDate}
/>
```

## Modal date input example

```tsx
<M3DatePickerDialog
  opened={opened}
  appearance="input"
  value={date}
  label="Trip date"
  onToggle={setOpened}
  onChange={setDate}
/>
```

# Выбор даты

Компоненты выбора даты позволяют выбрать одну дату в календарной сетке. `M3DatePicker` предоставляет поверхность календаря, сценарии с закреплённым полем собираются с помощью `M3DatePickerField`, а модальные сценарии — с помощью `M3DatePickerDialog`.

## API

`M3DatePicker` управляется через `value` и передаёт выбранную дату или диапазон в `onChange`. Используйте `layout="docked"` для компактной закреплённой поверхности Material; стандартный `layout="modal"` сохраняет заголовок и геометрию модального варианта.

Действия закреплённого календаря можно собрать через `M3DatePicker.Footer`. Компонент сам управляет контейнером футера и скрывает его, пока открыт список месяцев или лет.

`M3DatePickerField` объединяет `M3TextField`, кнопку с иконкой календаря и закреплённый popper. Значение остаётся типа `Date | null`; поддерживаются безопасные свойства текстового поля, включая `id`, `name`, `label`, `placeholder`, `invalid`, `disabled`, `readonly` и `outlined`. Введённые даты нормализуются в `MM/DD/YYYY`. Корневой `className`, `popperClassName` и составной `supportingText` дают локальные точки расширения формы, не перехватывая состояние календаря.

По умолчанию закреплённое поле использует outlined-вариант и открывает календарь в приподнятом popup под полем. Нажатие на день меняет локальный черновик: Cancel отменяет его, а OK передаёт результат в `onChange`.

`M3DatePickerDialog` оборачивает тот же календарь в модальную оболочку. Пока диалог открыт, значение хранится как черновик и попадает в `onChange` только после нажатия OK. `appearance="input"` включает модальный ввод даты Material; при включённом `switchable` можно переключаться между календарём и текстовым вводом.

`firstDayOfWeek` задаёт первый день недели, `min` и `max` отключают даты вне диапазона, а `availability` описывает дополнительные правила доступности дат и лет. Модальная раскладка всегда содержит шесть недель. Высота закреплённой раскладки следует поверхности M3 и показывает только необходимые четыре, пять или шесть строк.

Выбранное `value` и навигационный `cursor` — независимые состояния. Стрелки, выбор месяца или года и свайп двигают только курсор; `onChange` вызывается лишь после выбора дня. Используйте `cursor` и `onCursorChange`, когда положением календаря управляет родитель.

`navigation` задаёт вид навигации, а `views` — доступные состояния `days`, `months` и `years`. Стандартный `navigation="split"` остаётся вне области свайпа; `navigation="inline"` помещает управление внутрь каждой страницы месяца; `navigation="none"` скрывает его. Горизонтальный свайп между доступными месяцами всегда работает на календарной сетке.

В закреплённой раскладке выбор месяца и года открывает отдельные вертикальные списки. Активный список сохраняет свою кнопку доступной, отключает другую и после выбора возвращает сетку дней.

## Доступность

- Корень использует `role="group"` и получает доступное имя из `label`.
- Дни представлены как `grid` с одной строкой на неделю.
- Сетки выбора месяца и года используют семантику `grid`; закреплённые вертикальные селекторы — явные роли `list` и `listitem` через `M3List`.
- Каждый день — нативная кнопка с `aria-selected`.
- Недоступные даты используют нативный `disabled`.
- Кнопка месяца и года использует `aria-expanded`, пока открыт выбор года.
- Модальные сценарии используют `M3DatePickerDialog`, который получает семантику диалога через `M3Dialog`.

## Рекомендации

Используйте встроенный календарь, когда выбор даты — основная задача. Модальная композиция подходит, когда выбор даты временно прерывает работу с формой или компактным сценарием.

Закреплённое поле уместно внутри формы, когда выбранное значение должно оставаться видимым.

Показывайте ограничения диапазона через отключённые даты, а не скрывайте дни: так сетка месяца остаётся предсказуемой.

## Пример закреплённого поля

```tsx
const [date, setDate] = useState<Date | null>(new Date(2026, 6, 10))

<M3DatePickerField
  value={date}

  max={new Date(2026, 6, 24)}
  label="Дата поездки"
  name="trip_date"
  supportingText={<span>MM/DD/YYYY</span>}
  className="trip-date"
  popperClassName={['trip-date-popper', { 'trip-date-popper_open': true }]}
  placeholder="MM/DD/YYYY"

```
