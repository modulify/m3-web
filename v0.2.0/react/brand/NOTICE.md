# React artwork

The React orbit motif in `logo.svg` and `logo.png` is adapted from the
[Create React App logo](https://github.com/react/create-react-app/blob/main/packages/cra-template/template/src/logo.svg),
licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
It has been redrawn as three SVG ellipses with a nucleus and placed in a
transparent circular cutout at the lower right of the Modulify M3 mark.

The React artwork in these logo assets remains subject to CC BY 4.0; the
package's ISC license does not replace that artwork license.
