# Floating action buttons

Floating action buttons emphasize the highest-priority action on a surface. Material 3 treats FABs as strong directional cues, so they work best when the page has one clear "next thing to do."

## API

| Prop | Values | Default | Purpose |
| --- | --- | --- | --- |
| `variant` | `primary-container`, `secondary-container`, `tertiary-container`, `primary`, `secondary`, `tertiary` | `primary-container` | Paired container and content colors. |
| `size` | `sm`, `md`, `lg` | `sm` | FAB geometry: 56, 80, or 96px. |
| `disabled` | boolean | `false` | Prevent activation; prefer omitting an unavailable FAB. |

Pass an icon and optional text as children or in the default slot. Native button attributes and event handlers pass through.

### When to use

Use `M3FabButton` for the primary action of a screen or large section, especially when that action should remain easy to reach while content scrolls.

### Standard vs extended

- standard FAB for compact icon-first actions
- extended FAB when the action benefits from a visible label

The extended form is usually easier to scan when the action is not universally obvious from the icon alone.

### Variants

Choose a color role with `variant`: `primary-container` (default), `secondary-container`, `tertiary-container`, `primary`, `secondary`, or `tertiary`. The container role and its on-color stay paired.

### Sizes

`size="sm"` is the 56px default FAB, `md` is 80px, and `lg` is 96px. Keep it anchored over scrollable content with sufficient edge clearance.

Extended FABs use title-medium text at the small size, with larger type, icon spacing, and inner padding at the medium and large sizes. The spec recommends 16px clearance around an extended FAB. Keyboard focus is marked by an external focus ring.

## Accessibility semantics

- Icon-only FABs require an accessible name via `aria-label`.
- Keep FAB usage focused on the primary action on a given surface.
- Extended FABs should keep a short visible label.

## Usage guidance

### One FAB per context

Most surfaces should have at most one FAB. Multiple competing FABs dilute the main-action pattern that Material 3 is trying to reinforce.

### Prefer extended when the icon is ambiguous

If users need to stop and decode the icon, show the label. The slight increase in width is usually worth the clarity.

## Code example

```html
<M3FabButton>
  <M3Icon name="add" /> New task
</M3FabButton>
```

# Плавающие кнопки действий

Плавающие кнопки подчёркивают самое приоритетное действие на поверхности. FAB лучше всего работает, когда у страницы есть одно очевидное следующее действие.

## API

| Prop | Значения | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `variant` | `primary-container`, `secondary-container`, `tertiary-container`, `primary`, `secondary`, `tertiary` | `primary-container` | Цвета контейнера и содержимого. |
| `size` | `sm`, `md`, `lg` | `sm` | Геометрия FAB: 56, 80 или 96px. |
| `disabled` | boolean | `false` | Отключить действие; недоступную FAB лучше не показывать. |

Передайте иконку и необязательный текст через children или слот по умолчанию. Атрибуты и обработчики нативной кнопки передаются компоненту.

### Когда использовать

Используйте `M3FabButton` для основного действия экрана или крупного раздела, особенно если оно должно оставаться доступным при прокрутке.

### Обычный и расширенный варианты

- обычная FAB для компактного действия с иконкой
- расширенная FAB, когда действию нужна видимая подпись

### Варианты

Пара `variant` задаёт цвет контейнера и текста: `primary-container` (по умолчанию), `secondary-container`, `tertiary-container`, `primary`, `secondary` или `tertiary`.

### Размеры

`size="sm"` — стандартная FAB высотой 56px, `md` — 80px, `lg` — 96px. Размещайте её над прокручиваемым содержимым с достаточным отступом от края.

У малой расширенной FAB текст набран стилем title-medium; с увеличением размера растут шрифт, расстояние до иконки и внутренние отступы. Спек рекомендует оставлять вокруг расширенной FAB 16px. Клавиатурный фокус обозначен внешним кольцом.

## Доступность

- FAB только с иконкой требует доступного имени через `aria-label`.
- Используйте FAB для одного главного действия поверхности.
- Подпись расширенной FAB должна быть короткой.

### Обычные плавающие кнопки

<p style={{ display: 'flex', gap: '16px' }}>
  <Inline tag={'span'} is={ButtonExample} icon={'edit'} aria-label={'Изменить'} variant={'primary-container'} />
  <Inline tag={'span'} is={ButtonExample} icon={'edit'} aria-label={'Изменить'} />
  <Inline tag={'span'} is={ButtonExample} icon={'edit'} aria-label={'Изменить'} variant={'secondary-container'} />
  <Inline tag={'span'} is={ButtonExample} icon={'edit'} aria-label={'Изменить'} variant={'tertiary-container'} />
</p>

### Расширенные плавающие кнопки

<p style={{ display: 'flex', gap: '16px' }}>
  <Inline tag={'span'} is={ButtonExample} icon={'add'} label={'Новая задача'} variant={'primary-container'} />
  <Inline tag={'span'} is={ButtonExample} icon={'add'} label={'Новая задача'} />
  <Inline tag={'span'} is={ButtonExample} icon={'add'} label={'Новая задача'} variant={'secondary-container'} />
  <Inline tag={'span'} is={ButtonExample} icon={'add'} label={'Новая задача'} variant={'tertiary-container'} />
</p>

## Рекомендации

### Одна плавающая кнопка на контекст

На большинстве поверхностей должна быть не более чем одна FAB. Несколько конкурирующих кнопок размывают смысл главного действия.

### Подпись для неочевидной иконки

Если пользователю приходится расшифровывать иконку, показывайте подпись.
