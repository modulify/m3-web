# Menus

Menus present a short list of actions or choices anchored to a trigger. Material 3 menus are lightweight, contextual, and best for options that belong to the current place in the interface.

## API

### When to use

Use `M3Menu` for contextual actions, quick choices, and anchored command lists. If the content becomes long, descriptive, or form-like, prefer a side sheet or dialog.

### Anchoring

Menus should open from a clearly related trigger and preserve that relationship visually. The current implementation uses an explicit `target` element to keep positioning tied to the invoking control.

### Selection

Selected rows can communicate the current choice inside the menu, but the menu itself should still remain compact and easy to scan.

## Accessibility semantics

- Connect the trigger and popup with menu-button semantics.
- Keep item labels concise and action-oriented.
- Return focus to the trigger when the menu closes.

## Usage guidance

### Keep menus short

If users need to scroll, compare dense descriptions, or understand complex consequences, the control has probably outgrown the menu pattern.

### Prefer clear verbs

Menu items work best when each row starts with a distinct action or state label. Repetitive prefixes make scanning slower.

# Меню

Меню показывает короткий список действий или вариантов рядом с элементом, который его открыл. Меню Material 3 лёгкие, контекстные и лучше всего подходят для действий текущей области интерфейса.

## API

### Когда использовать

Используйте `M3Menu` для контекстных действий, быстрого выбора и компактных списков команд. Для длинного описательного содержимого или форм лучше выбрать боковую панель или диалог.

### Привязка

Меню должно открываться от явно связанного элемента. Реализация принимает `target`, чтобы позиционирование оставалось привязано к управляющему элементу.

### Выбор

Выбранная строка может показывать текущее значение, но само меню должно оставаться компактным и легко читаемым.

## Доступность

- Свяжите кнопку и всплывающее меню семантикой menu button.
- Делайте подписи краткими и ориентированными на действие.
- После закрытия возвращайте фокус на управляющий элемент.

## Рекомендации

### Делайте меню короткими

Если пользователю приходится прокручивать меню или сравнивать длинные описания, лучше выбрать другой паттерн.

### Используйте ясные глаголы

Строки легче просматривать, когда каждая начинается с отличимого действия или состояния.
