# Icon buttons

Icon buttons surface compact, frequent actions without introducing the visual weight of a full text button. They work best for toolbar actions, trailing row actions, and repeated local controls.

## API

### When to use

Use `M3IconButton` for secondary or utility actions where the icon metaphor is well established. If the action is high-stakes or not obvious from the icon alone, a text button is usually clearer.

### Appearances

Material 3 distinguishes icon buttons by fill and emphasis. This implementation covers `standard`, `filled`, `tonal`, and `outlined`, which map well to common local-action hierarchies.

### Toggleable state

When `toggleable` is enabled, the button should represent an on/off state such as favorite, pin, mute, or bookmark. In that mode, use selection styling together with `aria-pressed`.

## Accessibility semantics

- Icon-only controls must include an accessible name (`aria-label`).
- Toggleable icon buttons should expose state with `aria-pressed`.
- Use icon buttons for minor actions, not for primary destructive actions.

## Usage guidance

### Keep hit targets generous

Even when the visual icon is small, the interactive target should remain comfortable for pointer and touch use. Material 3 icon buttons depend on this spacing to feel intentional rather than fiddly.

### Use toggles only for persistent state

If the action simply opens a menu or triggers a one-off command, do not model it as selected. Reserve toggle state for something the user can inspect later.

## Code example

```tsx
<M3IconButton
  appearance="tonal"
  toggleable={true}
  selected={selected}
  aria-label="Toggle favorite"
  aria-pressed={selected}
>
  <M3Icon name="favorite" />
</M3IconButton>
```

# Кнопки с иконками

Кнопки с иконками дают компактный доступ к частым действиям без визуального веса полноценной текстовой кнопки. Они подходят для панелей инструментов, конечных действий в строках и повторяющихся локальных элементов управления.

## API

### Когда использовать

Используйте `M3IconButton` для вторичных и служебных действий с хорошо знакомой иконкой. Для рискованного или неочевидного действия обычно понятнее текстовая кнопка.

### Варианты оформления

Поддерживаются `standard`, `filled`, `tonal` и `outlined`, соответствующие распространённым уровням акцента локальных действий.

### Переключаемое состояние

При `toggleable` кнопка представляет состояние включено/выключено, например избранное, закрепление, отключение звука или закладку. Используйте оформление выбранного состояния вместе с `aria-pressed`.

## Доступность

- Элементу только с иконкой требуется доступное имя через `aria-label`.
- Переключаемая кнопка должна передавать состояние через `aria-pressed`.
- Не используйте иконку без текста для основных опасных действий.

<Unstyled>
  <p style={{ display: 'flex', gap: '16px' }}>
    <M3IconButton appearance="filled" aria-label="Добавить в избранное"><M3Icon name="favorite" /></M3IconButton>
    <M3IconButton appearance="filled" toggleable={true} selected={true} aria-label="Переключить избранное" aria-pressed="true">
      <M3Icon name="favorite" />
    </M3IconButton>
  </p>

## Рекомендации

### Достаточная область нажатия

Даже у небольшой иконки интерактивная область должна оставаться удобной для мыши и касания.

### Когда использовать переключаемое состояние

Если кнопка открывает меню или выполняет одноразовую команду, не моделируйте её как выбранную. Сохраняйте toggle-состояние для результата, который можно проверить позднее.

```tsx
  aria-pressed={selected}
>
  <M3Icon name="favorite" />
</M3IconButton>
```
