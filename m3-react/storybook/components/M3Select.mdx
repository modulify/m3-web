# Select

`M3Select` combines text-field presentation with a menu-backed option picker. It fits cases where the current value should stay visible in the form while the available choices open in an anchored list.

## API

### When to use

Use `M3Select` when users must choose one option from a structured list and the current choice should remain visible as field content. If freeform input is allowed, use a text field or autocomplete pattern instead.

### Composition

This implementation follows a hybrid pattern:

- field-like trigger for label, outline, support text, and current value
- listbox-style option popup for selection
- optional leading content for selected value and option rows

### Leading visuals

The `WithIcons` story demonstrates a useful Material 3 pattern for country, account, or category pickers where a compact visual cue speeds up recognition without replacing the text label.

## Accessibility semantics

- `M3Select` exposes combobox semantics with a listbox popup and option items.
- Provide a visible label through `label` or an explicit aria-label/aria-labelledby strategy.
- Keep option labels unique and meaningful for screen readers.

## Usage guidance

### Prefer stable option labels

Because the chosen option is mirrored back into the field, label wording should stay concise and unambiguous. Long, repetitive labels make the closed state harder to scan.

### Keep menus manageable

If the option set becomes very large, consider search or autocomplete instead of a pure select interaction.

## Code example

```tsx
<M3Select<number>
  value={value}
  label="Choose"
  options={[
    { label: 'Option 1', value: 1 },
    { label: 'Option 2', value: 2 },
  ]}
  onUpdate={setValue}
/>
```

# Поля выбора

`M3Select` сочетает оформление текстового поля с меню вариантов. Он подходит, когда текущее значение должно оставаться видимым в форме, а варианты открываются в привязанном списке.

## API

### Когда использовать

Используйте `M3Select` для выбора одного варианта из структурированного списка. Если разрешён произвольный ввод, используйте текстовое поле или autocomplete.

### Композиция

- триггер в виде поля с подписью, контуром, вспомогательным текстом и текущим значением
- всплывающий список вариантов
- необязательное ведущее содержимое для выбранного значения и строк вариантов

### Ведущие элементы

История `WithIcons` показывает выбор страны, учётной записи или категории с компактной визуальной подсказкой, которая ускоряет распознавание, не заменяя текст.

## Доступность

- `M3Select` предоставляет семантику combobox со всплывающим listbox и вариантами option.
- Задайте видимую подпись через `label` либо явный `aria-label`/`aria-labelledby`.
- Используйте уникальные и осмысленные подписи вариантов.
