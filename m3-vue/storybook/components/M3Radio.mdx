# Radio buttons

Radio buttons let users choose exactly one option from a related set. Unlike checkboxes, they are not meant for independent multi-selection or parent-child aggregate states.

## API

### When to use

Use `M3Radio` when the user must choose one option from a small, visible list. If multiple options can be selected together, prefer `M3Checkbox`.

### Selection model

This implementation treats each radio as a single-value option. A radio is checked when `model` equals `value`, and selecting it emits that `value`.

### Grouping

For native keyboard and form semantics, related radios should share the same `name`. Wrap related options in a `fieldset` with a visible `legend` whenever possible.

## Accessibility semantics

- Every radio needs a visible text label.
- Related radios should be grouped under a shared label.
- Use `name` consistently across one group so browser navigation behaves predictably.
- Mark the group or options invalid only when the selection is required and unresolved.

## Usage guidance

### Keep option sets short and explicit

Radio groups work best when all options are visible at once and labels are mutually exclusive.

### Do not use radios for toggles

If the choice is simply on/off, prefer a switch or checkbox. Radios communicate one-of-many selection.

# Радиокнопки

Радиокнопки позволяют выбрать ровно один вариант из связанного набора. В отличие от чекбоксов, они не предназначены для независимого множественного выбора.

## API

### Когда использовать

Используйте `M3Radio`, когда пользователь должен выбрать один вариант из небольшого видимого списка. Для выбора нескольких вариантов используйте `M3Checkbox`.

### Модель выбора

Радиокнопка отмечена, когда `model` равен `value`; выбор отправляет это `value`.

### Группировка

Для нативной клавиатурной и форменной семантики связанные радиокнопки должны иметь одинаковый `name`. По возможности объединяйте их в `fieldset` с видимым `legend`.

## Доступность

- Каждой радиокнопке нужна видимая текстовая подпись.
- Связанные варианты объединяйте общей подписью.
- Используйте один `name` внутри группы.
- Помечайте выбор невалидным только когда он обязателен, но не сделан.

## Рекомендации

### Короткий и понятный набор вариантов

Группа работает лучше всего, когда все варианты видны одновременно и взаимно исключают друг друга.

### Не заменяйте переключатели радиокнопками

Для простого состояния вкл./выкл. выберите switch или checkbox. Радиокнопки обозначают выбор одного из нескольких вариантов.
