# Split buttons

A split button pairs a primary action with a separate control for related actions. It uses two `M3Button` surfaces with a 2px gap. The trailing control opens a menu and rotates its expand icon when open. Unlike a connected button group, both controls are independent Tab stops; the split button has no selection model or arrow-key navigation. [Material guidelines](https://m3.material.io/components/split-button/guidelines).

<Canvas of={Stories.Open} />

## Choose a style and size

Material 3 Expressive specifies `elevated`, `filled`, `tonal`, and `outlined` split buttons at sizes `xs`, `sm`, `md`, `lg`, and `xl`. The inner gap stays 2px; inner corners use 4px for XS/S/M, 8px for L, and 12px for XL. The library also accepts `standard` and `text` because both halves use the common `M3Button` implementation. These combinations are library extensions outside the Material specification and are not recommended for Material-conformant interfaces. [Split button specs](https://m3.material.io/components/split-button/specs).

## API

| Prop | Values | Default | Purpose |
| --- | --- | --- | --- |
| `appearance` | Button appearances | `filled` | Color style of both buttons. |
| `size` | `xs`, `sm`, `md`, `lg`, `xl` | `sm` | Shared size of both buttons. |
| `menuLabel` | string | required | Accessible name of the trailing button. |
| `menu` | React content or `({ close }) => React content` | required | Menu content; call `close()` after handling an item. |
| `open` | boolean | `false` | Initial menu state and a command when the prop changes; interactions update state internally. |
| `onToggle` | `(open) => void` | — | State change notification. |
| `onAction` | button click handler | — | Primary action. |
| `disabled` | boolean | `false` | Disable both controls. |

A static `open` starts with the menu shown and still allows it to close. To open or close it later, change the prop value. The leading content is `children`. Native div attributes go to the group. The trailing button exposes `aria-haspopup`, `aria-expanded`, and `aria-controls`. Label it for the related options, not merely “More”. Both controls support Enter and Space independently. Keep the primary label brief and keep the menu visually aligned to the trailing side where space permits. [Accessibility](https://m3.material.io/components/split-button/accessibility).

```tsx
<M3SplitButton menuLabel="More sending options" onAction={send} menu={
  ({ close }) => <><M3MenuItem onClick={close}>Schedule send</M3MenuItem><M3MenuItem onClick={close}>Save draft</M3MenuItem></>
}>
  Send
</M3SplitButton>
```

# Разделённые кнопки

Разделённая кнопка сочетает основное действие и отдельное управление связанными действиями. Она состоит из двух поверхностей `M3Button` с зазором 2 px. Правая кнопка открывает меню, а её значок поворачивается при раскрытии. В отличие от соединённой группы кнопок, здесь две независимые остановки Tab; выбора и перемещения стрелками нет. [Рекомендации Material](https://m3.material.io/components/split-button/guidelines).

## Вид и размер

Material 3 Expressive описывает варианты `elevated`, `filled`, `tonal` и `outlined` в размерах `xs`, `sm`, `md`, `lg`, `xl`. Зазор всегда 2 px; внутренние скругления составляют 4 px для XS/S/M, 8 px для L и 12 px для XL. Библиотека допускает также `standard` и `text`, поскольку обе части используют общий `M3Button`. Эти сочетания являются расширением библиотеки за пределами спецификации Material; для интерфейса по Material они не рекомендуются. [Размеры split button](https://m3.material.io/components/split-button/specs).

## API

| Prop | Значения | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `appearance` | Варианты `M3Button` | `filled` | Общий цветовой стиль двух кнопок. |
| `size` | `xs`, `sm`, `md`, `lg`, `xl` | `sm` | Общий размер двух кнопок. |
| `menuLabel` | строка | обязательно | Доступное имя кнопки меню. |
| `menu` | React-контент или `({ close }) => React-контент` | обязательно | Содержимое меню; вызывайте `close()` после выбора пункта. |
| `open` | boolean | `false` | Начальное состояние меню и команда при изменении пропса; действия обновляют внутреннее состояние. |
| `onToggle` | `(open) => void` | — | Уведомление о смене состояния. |
| `onAction` | обработчик нажатия | — | Основное действие. |
| `disabled` | boolean | `false` | Отключение обеих кнопок. |

Статический `open` открывает меню при создании компонента, но не мешает закрыть его. Чтобы позднее открыть или закрыть меню программно, измените значение пропса. Основное содержимое передаётся через `children`. Атрибуты div передаются группе. Кнопка меню задаёт `aria-haspopup`, `aria-expanded` и `aria-controls`. В имени укажите, какие именно дополнительные действия она открывает. Обе кнопки независимо поддерживают Enter и Space. Подпись основного действия должна быть короткой; при наличии места меню выравнивается по стороне второй кнопки. [Доступность](https://m3.material.io/components/split-button/accessibility).

```tsx
<M3SplitButton menuLabel="Другие варианты отправки" onAction={send} menu={
  ({ close }) => <><M3MenuItem onClick={close}>Запланировать отправку</M3MenuItem><M3MenuItem onClick={close}>Сохранить черновик</M3MenuItem></>
}>
  Отправить
</M3SplitButton>
```
