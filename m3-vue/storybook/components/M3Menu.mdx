# Menus

Menus present a short list of actions or choices anchored to a trigger. Material 3 menus are lightweight, contextual, and best for options that belong to the current place in the interface.

M3 Expressive uses a rounded vertical menu. It has `standard` surface colors by default and an optional `vibrant` tertiary color scheme for stronger emphasis.

## API

| Component | Prop | Values | Default | Purpose |
| --- | --- | --- | --- | --- |
| `M3Menu` | `target` | function or Vue ref to an Element | required | Positioning anchor and focus return target. |
| `M3Menu` | `color` | `standard`, `vibrant` | `standard` | Expressive color mapping. |
| `M3Menu` | `density` | `0`, `-1`, `-2`, `-3` | `0` | Vertical item spacing on web. |
| `M3Menu` | `shown` | boolean | `false` | Programmatic visibility. |
| `M3MenuItem` | `selected` | boolean | `false` | Selection highlight. |
| `M3MenuItem` | `selection` | `single`, `multiple` | none | `menuitemradio` or `menuitemcheckbox` semantics. |
| `M3MenuItem` | `disabled`, `href` | boolean, URL | `false`, none | Unavailable action or destination. |

The `leading`, `trailing`, and `submenu` slots of `M3MenuItem` provide optional content. Use `M3Divider` between groups on web. `@update:shown` reports visibility changes; `@shown`, `@hide`, and `@hidden` report transition events.

### When to use

Use `M3Menu` for contextual actions, quick choices, and anchored command lists. If the content becomes long, descriptive, or form-like, prefer a side sheet or dialog.

### Anchoring

Menus should open from a clearly related trigger and preserve that relationship visually. The current implementation uses an explicit `target` element to keep positioning tied to the invoking control.

### Selection

Use `selection="single"` for one choice or `selection="multiple"` for independently checked choices, and control `selected` from application state. A plain selected action may be highlighted without choice semantics. Only one selection mode should be used in a group.

## Accessibility semantics

- Give the trigger `aria-haspopup="menu"`. If you control visibility, keep `aria-expanded` in sync and connect it with `aria-controls`.
- Keep item labels concise and action-oriented.
- Arrow keys, Home, End, and Escape support menu navigation; Escape returns focus to the trigger.
- Submenus open beside their parent on hover, click, or the forward arrow key. Keep each item a single action, including when its slots contain custom visuals.

## Usage guidance

### Keep menus short

Menus can scroll when their items do not fit. Material recommends a persistent scrollbar; this implementation styles the native scrollbar, whose visibility also follows browser and operating system settings. If choices need long descriptions, comparison, or form controls, use a more spacious pattern.

Use dividers to group items on web, especially in scrollable menus; do not add expressive gaps to a scrolling menu. Keep custom slots accessible and preserve a comfortable target size when choosing a denser menu.

### Prefer clear verbs

Menu items work best when each row starts with a distinct action or state label. Repetitive prefixes make scanning slower.

# Меню

Меню показывает короткий список действий или вариантов рядом с элементом, который его открыл. Меню Material 3 лёгкие, контекстные и лучше всего подходят для действий текущей области интерфейса.

M3 Expressive использует вертикальное меню со скруглёнными углами. По умолчанию применяется цветовая схема `standard` на основе surface; схема `vibrant` на основе tertiary даёт более сильный акцент.

## API

| Компонент | Свойство | Значения | По умолчанию | Назначение |
| --- | --- | --- | --- | --- |
| `M3Menu` | `target` | функция или Vue ref на Element | обязательно | Якорь позиционирования и возврата фокуса. |
| `M3Menu` | `color` | `standard`, `vibrant` | `standard` | Цветовая схема Expressive. |
| `M3Menu` | `density` | `0`, `-1`, `-2`, `-3` | `0` | Плотность строк на web. |
| `M3Menu` | `shown` | boolean | `false` | Программное отображение. |
| `M3MenuItem` | `selected` | boolean | `false` | Подсветка выбора. |
| `M3MenuItem` | `selection` | `single`, `multiple` | нет | Семантика `menuitemradio` или `menuitemcheckbox`. |
| `M3MenuItem` | `disabled`, `href` | boolean, URL | `false`, нет | Недоступное действие или ссылка. |

Слоты `leading`, `trailing` и `submenu` компонента `M3MenuItem` добавляют содержимое. Для групп на web используйте `M3Divider`. `@update:shown` сообщает об изменении видимости, `@shown`, `@hide` и `@hidden` — о переходах.

### Когда использовать

Используйте `M3Menu` для контекстных действий, быстрого выбора и компактных списков команд. Для длинного описательного содержимого или форм лучше выбрать боковую панель или диалог.

### Привязка

Меню должно открываться от явно связанного элемента. Реализация принимает `target`, чтобы позиционирование оставалось привязано к управляющему элементу.

### Выбор

Используйте `selection="single"` для единственного выбора или `selection="multiple"` для независимых пунктов. Состояние `selected` задавайте из приложения. Обычное действие тоже можно визуально подсветить без семантики выбора. В одной группе придерживайтесь одного режима выбора.

## Доступность

- Укажите кнопке `aria-haspopup="menu"`. При программном управлении синхронизируйте `aria-expanded` и при необходимости свяжите меню через `aria-controls`.
- Делайте подписи краткими и ориентированными на действие.
- Стрелки, Home, End и Escape управляют фокусом; Escape возвращает его кнопке.
- Вложенное меню открывается рядом с пунктом по наведению, нажатию или стрелке вперёд. Даже с произвольным содержимым слота пункт должен оставаться одним действием.

## Рекомендации

### Делайте меню короткими

Если пункты не помещаются, меню можно прокручивать. Material рекомендует постоянно видимую полосу прокрутки; здесь стилизована нативная полоса, видимость которой также зависит от браузера и настроек ОС. Для выбора с длинными описаниями, сравнением или элементами формы нужен более просторный паттерн.

На web разделяйте группы линиями, особенно в прокручиваемом меню; промежутки между группами в нём не используйте. Произвольные слоты должны оставаться доступными, а плотность не должна делать пункты неудобными для нажатия.

### Используйте ясные глаголы

Строки легче просматривать, когда каждая начинается с отличимого действия или состояния.
